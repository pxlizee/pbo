# Program Toko Retail

Program ini adalah aplikasi console sederhana untuk mengelola data barang pada toko retail.

## Fitur
- Menampilkan semua data barang
- Menambahkan data barang baru
- Mencari data barang berdasarkan kode atau nama
- Mengubah data barang
- Menghapus data barang
- Keluar dari program

## Cara Menjalankan
1. Buka terminal
2. Masuk ke folder proyek
3. Jalankan perintah berikut:

```bash
javac TokoRetail.java
java TokoRetail
```

## Contoh Data Awal
- B001 - Roti Tawar
- B002 - Malkist
- B003 - Kopi Kapal Api

## Catatan
Program ini dibuat menggunakan bahasa Java dan memanfaatkan list untuk menyimpan data barang secara sementara saat program berjalan.
