# ☕ Kumpulan Tugas Pemrograman Berorientasi Objek (Java)

Selamat datang di repositori penyimpanan tugas praktikum dan teori untuk mata kuliah **Pemrograman Berorientasi Objek (Object-Oriented Programming - OOP)** menggunakan bahasa pemrograman **Java**. 

Repositori ini disusun secara terstruktur berdasarkan sesi perkuliahan, mencakup dasar-dasar sintaks Java, konsep OOP fundamental (*Inheritance, Polymorphism, Encapsulation, Abstraction*), penanganan I/O file, GUI desktop (Swing), koneksi database (JDBC), hingga aplikasi web modern (Spring Boot & Docker).

## 🛠️ Lingkungan Pengembangan (Development Environment)
Untuk menjalankan tugas-tugas di dalam repositori ini, disarankan menggunakan spesifikasi lingkungan berikut:
- **JDK**: Java SE 17 LTS (atau Java 8 minimal untuk program Swing CLI dasar).
- **IDE**: Visual Studio Code (dengan *Extension Pack for Java*) atau NetBeans IDE.
- **Database**: MySQL Server 8.0+.
- **Virtualisasi**: Docker & Docker Compose (untuk Projek Mandiri).
