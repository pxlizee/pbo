# Tugas Sesi 1 PBO - Pengenalan Dasar Java & Dialog Box

Sesi ini berisi latihan awal pengenalan sintaks dasar bahasa pemrograman Java, yang mencakup pencetakan teks ke console dan interaksi pengguna sederhana menggunakan Dialog Box (`JOptionPane`).

---

## 📂 Daftar Tugas

### 1. Tugas 1: Belajar Java Console (`Tugas1.java`)
Program console sederhana untuk menampilkan beberapa baris kalimat pemberitahuan tentang pembelajaran Java.
- **Sintaks Utama**: `System.out.println()`

**Cara Menjalankan**:
```bash
javac Tugas1.java
java Tugas1
```

---

### 2. Tugas 2: Latihan Dialog Box (`Tugas2.java`)
Program interaktif sederhana menggunakan pustaka Swing `JOptionPane` untuk meminta input teks dari pengguna dan menampilkan pesan hasil olahan input tersebut dalam pop-up dialog box.
- **Sintaks Utama**: 
  - `JOptionPane.showInputDialog(...)`
  - `JOptionPane.showMessageDialog(...)`

**Cara Menjalankan**:
```bash
javac Tugas2.java
java Tugas2
```

---

## ⚙️ Teknologi yang Digunakan
- **Bahasa**: Java
- **Library**: `javax.swing.JOptionPane`
- **JDK**: Java 8 atau versi terbaru
